# [과거 대화 기록 요약] 실존주의 대시보드 프로젝트

## 📝 4월 13일: Analyzing KCI Research Data (KCI 연구 데이터 분석)
- **주요 목표:** KCI 엑셀 데이터를 구조화된 JSON 데이터로 변환하고 프리미엄 다크 테마의 대시보드 기초 구축하기.
- **주요 내용:**
  - KCI 엑셀 데이터를 파이썬(`scripts/process_data.py` 등)으로 파싱하여 `dashboard_data.json`으로 추출.
  - HTML, CSS, ECharts를 사용하여 '자유(Freedom)'와 관련된 영향력 랭킹(Focus Gauge), 키워드 네트워크(Navigation Map), 연도별 연구 밀도(Timeline) 컴포넌트 뼈대 완성.
  - 깃(Git) 저장소 초기화 및 불필요/민감한 파일을 거르는 `.gitignore` 파일 작성.

## 📝 4월 15일: Launching Existentialism Research Dashboard (실존주의 연구 대시보드 런칭)
- **주요 목표:** 발견된 '연구 공백(Research Gap)'을 자동 식별하고, 나만의 논지 발견(Analyst's Insight) 패널을 추가하여 대시보드의 학술적 가치 완성하기.
- **주요 내용:**
  - 네트워크 그래프 상에서 빈도가 낮지만 중요한 '연구 공백' 지점을 붉은 점선으로 식별하고 교차 필터링 적용.
  - Analyst's Insight 메모장 영역을 우측 하단에 추가하여 논문의 결론을 도출할 수 있도록 지원.
  - 모든 HTML, CSS, JS 및 JSON 데이터를 로컬 서버 없이 어디서든 열어볼 수 있도록 1개의 단일 포터블(Portable) HTML 파일(`build_single_file.py`)로 묶어 배포.
